## 📌 About The Project

**ATTEND X** is a Smart Campus Intelligence Platform developed to make traditional classroom attendance management faster, easier, and more organized.

The application provides an interactive administrator dashboard where users can manage student information, create QR-based attendance sessions, monitor attendance records, and generate reports.

The platform aims to reduce manual paperwork and provide a centralized interface for managing classroom attendance.

## ✨ Key Features

### 📊 1. Smart Dashboard
- Total registered students overview.
- Present and absent student statistics.
- Daily attendance percentage.
- Attendance overview and activity monitoring.
- Quick access to important modules.

### 👨‍🎓 2. Student Management
- Register new students.
- Store student names and roll numbers.
- Manage course and email information.
- Search and view registered students.
- Maintain a centralized student directory.

### 📱 3. QR Code Attendance
- Create attendance sessions.
- Generate QR codes for classroom sessions.
- Configure QR session expiry.
- Provide a student QR scanning interface.
- Support demo attendance marking using roll numbers.

### 📋 4. Attendance Management
- View attendance records.
- Track present and absent students.
- Monitor student check-in information.
- Maintain attendance history.

### 📈 5. Reports & Analytics
- View attendance statistics.
- Monitor student attendance performance.
- Identify students with low attendance.
- Export attendance records as CSV.

## 🚀 Getting Started

Follow these steps to run the project locally.

### Prerequisites

- A computer with Windows, macOS, or Linux.
- A modern web browser.
- Visual Studio Code (recommended).

### Installation

**Step 1: Clone the repository**

```bash
git clone https://github.com/sashankarsaikia101-sys/Campus-intelligence-platform-Dashboard.git
```

**Step 2: Open the project folder**

```bash
cd Campus-intelligence-platform-Dashboard
```

**Step 3: Run the application**

Open `index.html` in your browser.

Alternatively, use the Live Server extension in Visual Studio Code.
